# CR-0006 I1·I3의 목록 호출 공백

- 상태: **결정됨(D42, boundary-contracts v1.0.0), 구현에 반영함.** 대상: `INTERFACES.md` I1, I3.
- 내용: (1) I1과 I3에는 문항 세트 ID, 패키지 ID를 나열하는 호출이 없다. 후보 수집기는 감시할 ID를 설정으로 받는다. (2) I3 `list_versions`의 정렬이 정해져 있지 않다(I2는 오래된 것부터). 수집기는 순서를 가정하지 않고 각 매니페스트의 `created_at`이 가장 늦은 것을 최신으로 본다.
- 요청: 나열 호출 추가 또는 현행 유지 확인, I3 정렬 명시.
